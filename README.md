# wizardTracker

Project Goal : Create a program to be used alongside the Wizard card game. The program is capible of both calculating and keeping, as well as storing player stats.

MVP Scope : MVP will be able to calculate score, and store W/L ratoio for players.

Future Plans : In the futre, I plan on introducing a better UI, more detailed player statistics, automated win detection, and support for adding a player in mid round. 

Tech Stack : 
- Language : Java
- Libraries / Commands:
    - Print Writer
    - Buffered Reader
    - Array List
- Data Storage: .csv
